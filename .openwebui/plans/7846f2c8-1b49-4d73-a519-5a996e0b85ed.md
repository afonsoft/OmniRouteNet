## 6. Acceptance Criteria

- **AC-01** Given `.specs/README.md`, When leio o pin, Then vejo `191dce8d534ceb56c28a08e71381284a9a87838f` e `v3.8.53`.
- **AC-02** Given o gap doc, When conto os itens da §3.3, Then todos têm status e SPEC.
- **AC-03** Given device code emitido, When aprovado em `/cli/device?code=`, Then o poll retorna `{token,scope:"cli"}`; e com device code expirado o poll retorna `expired_token`.
- **AC-04** Given processo sem `LLMROUTER_TEST_MODE`, When `POST /api/test/seed`, Then 404.
- **AC-05** Given sink offline, When chegam 100 eventos, Then a latência do gateway não muda (p50 ±10%) e a fila descarta os mais antigos.
- **AC-06** Given combo fallback com o 1º alvo em cooldown, When a request completa, Then `route-decision` mostra o 1º com `skipReason=cooldown` e o 2º com `selected=true`.
- **AC-07** Given `ui-parity.json` sem uma rota da tag, When o teste roda, Then falha nomeando a rota.
- **AC-08** Given um DB do LLMRouter N-1, When aplico as migrações, Then os dados são preservados.
- **AC-09** Given `en.json` com a chave X, When o teste de i18n roda, Then pt-BR e es também têm X.
- **AC-10** Given o stream truncado de um provider antes do primeiro conteúdo, When está em combo, Then ocorre failover para o próximo alvo (SPEC-165 `truncatedStreamFailover`).
- **AC-11** Given um usuário com MFA ativo, When faz login sem TOTP válido, Then o acesso é negado.
- **AC-12** Given `dotnet test --filter FullyQualifiedName~CliDeviceTests`, When rodo localmente, Then termina em < 30 s.
- **AC-13** Given uma janela de quota 7d persistida como esgotada, When a próxima leitura completa do provider traz só a janela 5h, Then a janela 7d é aposentada e a conexão volta a ser elegível no roteamento; e Given uma leitura incompleta, Then nada é aposentado.
- **AC-14** Given login do dashboard desativado, When `PUT` numa feature flag protegida sem auth de gerenciamento, Then 401/403; e Given valor fora do enum, Then 400.

| Scenario | Input | Expected behavior |
|---|---|---|
| Poll rápido demais | intervalo < `interval` | `slow_down` |
| Seed repetido | 2× seed | sem duplicatas |
| Sink com URL inválida | test | 502 sanitizado (sem stack/headers) |
